# Tiny RACI — ماتریس مسئولیت

ماژول ساده TinyManager برای مشخص‌کردن مسئولیت‌ها بدون فرم سنگین.

حداقل ورودی فقط:

- فعالیت
- Responsible — مسئول اجرا
- Accountable — پاسخگو

Consulted و Informed اختیاری‌اند.

## Alpha

- Standalone App
- TinyManager Module package
- Local-first repository
- اتصال اختیاری به پروژه
- TypeScript declarations + tests + CI

نسخه: `0.1.0-alpha.1`
