# Tiny RACI

A minimal TinyManager RACI builder without a heavy setup flow.

Minimum input:

- Activity
- Responsible
- Accountable

Consulted and Informed remain optional.

## Alpha

- Standalone app
- TinyManager module package
- Local-first repository
- Optional project link
- TypeScript declarations, tests and CI

Version: `0.1.0-alpha.1`
